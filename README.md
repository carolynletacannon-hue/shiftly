# Shiftly

A mobile-first scheduling tool for small teams.

**Status:** Frontend demonstration only. All schedules and requests use fictional data, and changes do not persist.

## Stack
Next.js App Router, TypeScript, React, CSS. Deploy on Vercel from GitHub.

## Roadmap
1. Demo UI and Vercel deployment
2. Supabase authentication, organization membership, role-based access
3. Draft and published schedules
4. Time-off requests, swaps, manager approvals
5. Private iCalendar subscriptions and email notifications

Do not add real employee or guest data before workplace approval and production-ready authentication/security.
